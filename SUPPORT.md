# Support

## Getting help

Use the right channel so we can help faster:

- Bug report: open a GitHub issue with reproduction details
- Feature request: open a GitHub issue with the use case and expected behavior
- Security report: use the private path described in `SECURITY.md`

## Before opening an issue

Please check:

1. `README.md`
2. `docs/getting-started.md`
3. `docs/integration-guide.md`
4. `docs/troubleshooting.md`

## Helpful details to include

- operating system
- Node.js version
- Electron version
- package manager
- exact error output
- whether SSH, CI, or local mode was detected
