# Code of Conduct

## Our Standard

We want this project to be welcoming, safe, and constructive for everyone. Contributors are expected to be respectful, collaborative, and considerate in discussions, reviews, and issue threads.

Examples of positive behavior:

- being respectful in disagreement
- assuming good intent
- giving actionable feedback
- helping newer contributors get oriented

Examples of unacceptable behavior:

- harassment, insults, or personal attacks
- discriminatory language or behavior
- trolling, derailing, or deliberately hostile conduct
- publishing private information without permission

## Scope

This Code of Conduct applies in:

- GitHub issues
- pull requests
- discussions
- project communication channels tied to this repository

## Enforcement

Project maintainers may remove comments, close discussions, or restrict participation for behavior that violates this Code of Conduct.

## Reporting

Report serious issues privately to the maintainers through the security/support channels listed in this repository.
