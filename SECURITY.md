# Security Policy

## Reporting a vulnerability

Please do not open public GitHub issues for security-sensitive reports.

Instead, report vulnerabilities privately to the maintainers with:

- a description of the issue
- affected versions
- reproduction steps
- impact assessment
- any suggested mitigation

## Response goals

- We will acknowledge reports as quickly as possible.
- We will investigate and validate the issue.
- We will coordinate a fix and release when needed.

## Scope

Security reports are especially helpful for:

- unsafe Electron integration patterns
- environment detection bypasses
- packaging or distribution issues
- supply-chain or installation concerns
